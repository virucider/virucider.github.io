# Starforge Developer Website

Static, mobile-friendly Starforge homepage. No analytics, tracking scripts, forms or cookies are added by the site.

Intended repository: virucider/virucider.github.io
Website once GitHub Pages is enabled: https://virucider.github.io/
AdMob verification file: https://virucider.github.io/app-ads.txt
Privacy policy: https://sites.google.com/view/starforgeprivacypolicy/home
Google Play: https://play.google.com/store/apps/details?id=com.fournvl.starforge

The app-ads.txt file must live at the domain root, so a /Starforge/ project Pages site is not the intended deployment.

Publishing: place these files at the root of the virucider.github.io repository, then set Settings > Pages > Deploy from a branch > main > /(root). Enter https://virucider.github.io/ in Play Console's developer Website field once live. The privacy-policy field stays on Google Sites. After the store website link is publicly visible, use AdMob's Check for updates.
